# The Listening Commons

A living research commons for human-led, AI-assisted, human-AI co-developed, and AI-led human-curated scholarship.

This repository contains the founder kit and a minimal static website prototype.

## Founder Kit

- `charter.md` - the founding charter and principles
- `submission-form-v1.md` - the first submission form
- `paper-page-template.md` - the public page structure for each submission
- `validation-rubric.md` - the Listening Scale and review criteria
- `contribution-modes.md` - how submissions disclose human/AI roles
- `mvp-build-plan.md` - the minimum viable platform roadmap
- `examples/covenant-and-vessel.md` - a sample Listening Page

## Static Prototype

- `index.html` - Home
- `charter.html` - Charter
- `submission.html` - Submit
- `contribution-modes.html` - Contribution Modes
- `validation-rubric.html` - Validation Rubric
- `browse.html` - Browse Papers
- `papers/covenant-and-vessel.html` - Sample Paper

Open `index.html` directly in a browser to view the prototype. No backend or build step is required.

Core principle:

> AI assistance is allowed. Human inhabitation is required. AI-led is not disqualifying. Unaccountable is disqualifying.
