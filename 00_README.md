# The Listening Commons — Founder Kit

A living research commons for human-led, AI-assisted, human–AI co-developed, and AI-led human-curated scholarship.

This folder contains the first practical artifacts needed to make the project real:

1. `01_charter.md` — the founding charter and principles.
2. `02_submission_form_v1.md` — the first submission form.
3. `03_paper_page_template.md` — the public page structure for each submission.
4. `04_validation_rubric.md` — the Listening Scale and review criteria.
5. `05_contribution_modes.md` — how submissions disclose human/AI roles.
6. `06_mvp_build_plan.md` — the minimum viable platform roadmap.
7. `07_sample_page_covenant_and_vessel.md` — a sample paper page.

Core principle:

> AI assistance is allowed. Human inhabitation is required. AI-led is not disqualifying. Unaccountable is disqualifying.
